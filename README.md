# 📓 Notebook — تطبيق إدارة المستندات

<div dir="rtl">

## نظرة عامة

تطبيق **Notebook** هو منصة احترافية لإدارة وإنشاء وتحرير جميع أنواع المستندات على الهواتف الذكية. يعمل بالكامل دون اتصال بالإنترنت، مع واجهة سهلة وبسيطة، وبنية قابلة للتوسع.

**حقوق التطوير: © أحمد عبد الودود الدبعي**

---

## ✨ المميزات الرئيسية

### 📄 إدارة المستندات
- دعم جميع أنواع المستندات: ملاحظات، دفاتر، محاضرات، تقارير، فواتير، عقود، كتب، برمجة
- أنواع الملفات: Markdown، HTML، TXT، JSON، CSV، ومستندات مخصصة
- حفظ تلقائي كل 5 ثوانٍ
- عرض قائمة أو شبكة

### 📁 تنظيم الملفات
- إنشاء مجلدات وتصنيف المستندات
- نقل المستندات بين المجلدات
- أرشفة المستندات وسلة المحذوفات
- مفضلة للوصول السريع

### 🖊️ محرر المستندات
- تنسيق نصي كامل (عريض، مائل، تسطير، شطب)
- قوائم نقطية ورقمية ومربعات اختيار
- كتابة أكواد برمجية واقتباسات
- عداد الكلمات والأحرف

### 📋 نظام القوالب
- قوالب جاهزة لكل نوع مستند
- إنشاء قوالب مخصصة
- تعديل وحذف ونسخ القوالب

### 🔍 البحث المتقدم
- بحث فوري في العنوان والمحتوى
- تصفية حسب النوع والتاريخ والوسوم

### 📤 التصدير والاستيراد
- تصدير إلى: PDF، TXT، HTML، Markdown، JSON، CSV، ZIP
- استيراد الملفات المدعومة

### 🎨 واجهة المستخدم
- دعم كامل للغة العربية واتجاه RTL
- الوضع الداكن والفاتح والتلقائي
- تصميم Material Design 3
- خط Cairo لأفضل قراءة عربية

## 🏗️ المعمارية (Clean Architecture)

```
lib/
├── main.dart                    # نقطة الدخول
├── app.dart                     # إعداد التطبيق
├── core/                        # المكونات الأساسية
│   ├── constants/              # الثوابت
│   ├── errors/                 # معالجة الأخطاء
│   ├── router/                 # التنقل (go_router)
│   ├── theme/                  # الثيم والألوان
│   └── utils/                  # أدوات مساعدة
├── data/                        # طبقة البيانات
│   ├── datasources/            # قاعدة البيانات SQLite
│   ├── models/                 # نماذج البيانات
│   └── repositories/           # تنفيذ المستودعات
├── domain/                      # طبقة الأعمال
│   ├── entities/               # الكيانات
│   ├── repositories/           # واجهات المستودعات
│   └── usecases/               # حالات الاستخدام
└── presentation/               # طبقة العرض
    ├── providers/              # Riverpod providers
    ├── screens/                # الشاشات
    └── widgets/                # الـ Widgets المشتركة
```

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |

## 🚀 تثبيت وتشغيل المشروع

### المتطلبات
- Flutter SDK >= 3.10.0
- Dart SDK >= 3.0.0
- Android Studio أو VS Code

### خطوات التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/alhlwqya-debug/Notebook.git
cd Notebook

# تثبيت الاعتماديات
flutter pub get

# تشغيل التطبيق
flutter run

# بناء للإصدار
flutter build apk --release
```
